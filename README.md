# Quickshell

This is the native Windows backend fork used by
[Caelestia for Windows](https://github.com/KldsSeeGhosts/caelestia-windows).
It retains upstream Quickshell and the Windows work from
[nunreasonable/quickshell](https://github.com/nunreasonable/quickshell).
Use [BUILD.md](BUILD.md#windows-backend) for the Windows toolchain and
production build instructions. The material below describes upstream Quickshell.

See the [website](https://quickshell.outfoxxed.me) for more information
and installation instructions.

This repo is hosted at:
- https://git.outfoxxed.me/quickshell/quickshell
- https://github.com/quickshell-mirror/quickshell
